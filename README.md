# HTML Figure and Figcaption

## Explanation

This program demonstrates the use of the HTML figure and figcaption elements.

The figure element is used to group media content such as images.

The figcaption element provides a caption or description for the content inside the figure.

## Problem Statement

Create an HTML webpage that displays images along with meaningful captions using figure and figcaption elements.

## Features

- Displays images
- Adds captions to images
- Groups images with related content
- Uses semantic HTML elements
- Provides alternative text for images

## How It Works

The <figure> element groups an image and its related caption.

The <img> element displays the image.

The <figcaption> element provides a caption for the image.

The alt attribute provides alternative text if the image cannot be displayed.
